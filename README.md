# Search Images Application (Flutter)

플러터 앱 개발 라이프 사이클을 구현하기 위해 API 호출부터 내부 데이터베이스 저장까지 구현한 프로젝트 입니다.

## 📖 프로젝트 소개

이미지를 검색할 수 있는 서비스 입니다. 간단하게 입력어를 통해서 이미지를 검색하고 클릭해서 저장할 수 있습니다.

## 🛠 기술 스택

Language : Dart<br>
provider : Flutter 상태 관리 및 앱 전체 구조<br>
http : 네트워크<br>
sqflite : 로컬 데이터베이스<br>

## ✨ 주요 기능

-   이미지 검색 API 호출
-   내부 데이터베이스에 이미지 저장
